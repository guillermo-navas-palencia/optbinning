Installation
============

OptBinning 1.0.0 requires Python 3.11 or newer. The legacy ``setup.py``
installation workflow is no longer supported; use ``pip install`` instead.

Install release
---------------

To install the current release of OptBinning:

.. code-block:: text

   pip install optbinning

Optionally, download a different release
from https://github.com/guillermo-navas-palencia/optbinning/releases and install
using

.. code-block:: text

   cd optbinning-<release>
   pip install .

Install from source
-------------------

To install from source, download or clone the git repository https://github.com/guillermo-navas-palencia/optbinning

.. code-block:: text

   cd optbinning
   pip install .
